# 麻衣面相美学 · mayi-face-aesthetics

> 把《麻衣神相》翻译成「状态美学」的 Agent Skill。
> **只讲观感与妆容启发，拒绝一切命运断语。**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 这是什么

一个面向 AI Agent 的 skill（兼容 Kimi Work / Kimi CLI / Claude Code 的 Skill 规范），内置一部基于《图解麻衣神相》整理的**面相美学知识库**：

- **框架**：十三部位、十二宫、三停三才六府、五观五岳四渎、五星六曜学堂、五行形象、流年部位坐标
- **五官**：24 种眉形、39 种眼形、24 种鼻形、16 种口形、16 种耳形的逐形态名目表——每一条都标注原书卷次与页码
- **气色**：七种神、神主眼七条、四时气色、三停分区气色、明滞转化
- **痣纹**：面痣三色分类、毫毛、髭髯、鱼尾纹
- **女相**：古籍女相记载的完整文献转述（史料立场，含时代局限标注）
- **应用**：九个内容系列选题规划，每个选题配 ✅ 安全写法 / ❌ 越线写法对照

## 它和其他「看相 skill」有什么不同

| | 本 skill | 常见看相类 skill |
|---|---|---|
| 立场 | 只解释「观感」，永远不承诺「命运」 | 输出性格/运势/职业断语 |
| 断语处理 | 一律「古籍记载」文献口吻封存，标注页码与时代局限 | 直接当结论使用 |
| 颗粒度 | 119 种五官形态名目 + 原书页码级出处 + OCR 校勘标注 | 常识级浓缩条目 |
| 合规 | 四类禁用词、五类禁用句式、安全替换表、审稿流程写死在 SKILL.md 里 | 一句免责声明了事 |

**一句话：别的 skill 让 AI 当相师，这个 skill 让 AI 当「用相术框架讲观感的化妆顾问」。**

## 安装

把整个 `mayi-face-aesthetics/` 目录复制到你的 skills 目录即可：

- **Kimi Work / Kimi CLI**：`~/.kimi/skills/`（Windows 下为 `%APPDATA%\kimi-desktop\daimon-share\daimon\skills\`）
- **Claude Code**：`~/.claude/skills/`

```bash
git clone https://github.com/memilin/mayi-face-aesthetics.git
cp -r mayi-face-aesthetics ~/.kimi/skills/
```

## 使用

安装后，在任意会话中说：

- 「帮我看看面相」（只会得到观感描述 + 妆容建议 + 不看命声明）
- 「麻衣神相里眉形有哪些名目」
- 「古籍说的『气色昏浊』是什么意思」
- 「帮我做个面相美学的短视频选题」

SKILL.md 按问题类型路由到 `references/` 下的七个分篇，知识库按需加载。

## 红线声明（也是本项目的立场声明）

本项目中的一切相术内容均为**古籍文献记录**，只用于理解观感与审美：

- 不出现改运、招财、旺夫、克夫、化解、转运类表述；
- 不对任何真实个人下性格、命运、婚姻、健康判定；
- 健康话题一律以医学为准；
- 女相等时代局限内容仅作史料讲解，严禁现代套用。

完整清单见 `references/06-议题应用篇.md` 的「全账号禁忌表述清单」。

## 来源与校勘

知识库基于《图解麻衣神相》（宋代相书，托名麻衣道者）卷一《相法总论》、卷二《察言观色》、卷三《五官相法》、卷五《达摩相诀》、卷六《石室神异赋》、卷七《论三庭吉凶》整理。每条标注原书页码；OCR 残缺或两书互异处均以「存疑」注明，不作臆补。
